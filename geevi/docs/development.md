## Run it (no Docker)

```bash
pnpm install --frozen-lockfile
uv sync --project apps/api --frozen
./scripts/dev-db.sh start                 # dedicated PostgreSQL cluster in .pgdata, port 5433
pnpm api:migrate                          # alembic upgrade head
pnpm api:seed                             # fictional accounts + an empty demo workspace
pnpm api:dev                              # FastAPI on :8000 (development mode)
pnpm web:dev                              # Next.js on :3000, proxies /api/v1 to FastAPI
```

Open <http://127.0.0.1:3000>. Useful variants:

```bash
cd apps/api && GEEVI_DEV_MODE=true uv run python scripts/seed_demo.py --name "Demo with sources" --load sources
./scripts/dev-db.sh reset && pnpm api:migrate && pnpm api:seed    # start over
./scripts/dev-db.sh stop
```

`--load patients` registers Meera and Arun; `--load sources` also receives their baseline documents, unassociated
and unreviewed. Seeding never creates reviews, approvals, publications or signatures.

## Run it (Docker Compose)

```bash
docker compose up --build
```

Order: PostgreSQL health → one-shot Alembic migration → one-shot demo seed → FastAPI → Next.js. Ports are published on
loopback only. Passwords are written to `.geevi-local/dev-credentials.json`. `docker compose config` validates;
the stack itself was **not** run during this build because no Docker daemon was available (see the guide).

## Architecture boundaries

- **FastAPI owns every rule.** Authentication, resource scope, capability and independence checks, review/approval
  guards and transactions live in `apps/api/app/services/`. Routes delegate to services.
- **One transactional command path.** `services/command_service.py` locks the workspace row, checks the idempotency
  receipt (actor + payload digest), runs the guarded handler, appends audit events and stores the receipt in one
  transaction. Entities use revision compare-and-set; unrelated writes never stale each other.
- **Scoped currency.** A plan packet freezes its read set and the revisions of its watched scopes
  (`services/review_dependencies.py`, `services/scopes.py`); both are re-checked under the lock at signature time.
- **Next.js owns pages only.** `apps/web/next.config.ts` proxies `/api/v1/*` to FastAPI. There is no Next.js route
  handler, server action or database access. All requests go through `apps/web/src/lib/api/client.ts`, typed from
  the generated `schema.d.ts`. Server state is TanStack Query in memory; drafts are React state.
- **Containers.** Every domain record has key `(container_id, id)`. A restore or legacy import is written to a
  separate staging container with the original logical ids and only becomes active by an explicit command.
- **Append-only history.** Migration `0006` adds triggers that reject any UPDATE of decisions, approvals, audit
  events, receipts and original bytes.

## Commands

| Check | Command |
|---|---|
| Backend lint | `pnpm api:lint` |
| Backend domain/HTTP/PostgreSQL tests | `uv run --project apps/api pytest apps/api/tests` (or `pnpm api:test`) |
| Frontend lint / types / components / build | `pnpm --dir apps/web lint` · `typecheck` · `test` · `build` |
| Contract is current | `pnpm contracts:check` (regenerate with `pnpm contracts:generate`) |
| Browser journeys | `pnpm --dir apps/web exec playwright test` (first time: `playwright install chromium`) |
| Regenerate fixtures | `pnpm fixtures:make` |
| New migration | `cd apps/api && uv run alembic revision --autogenerate -m "..."` |

Backend tests create a disposable database (`geevi_test_<random>`) on the dev cluster, run the real migrations, and
drop it afterwards; the archive test additionally restores into a second, empty database. Override the server with
`GEEVI_TEST_ADMIN_URL`. SQLite and mocks are never used for transaction or locking tests.

Browser tests start their own API (fresh database `geevi_e2e`, fresh fictional passwords in
`apps/api/.e2e-credentials.json`) and a production build of the web app in `.next-e2e`. They do not touch the
development database or `.next`.

## After changing the API

1. Change models/schemas/services/routes and add a migration.
2. `pnpm contracts:generate` and commit `contracts/openapi.json` and `apps/web/src/lib/api/schema.d.ts`.
3. Update the frontend; `pnpm --dir apps/web typecheck` shows every affected call.

## Troubleshooting

- `initdb: invalid locale settings`: `scripts/dev-db.sh` already exports `en_US.UTF-8`; make sure that locale exists.
- Port 8010 or 3010 busy after an interrupted browser run: `lsof -ti tcp:8010 tcp:3010 | xargs kill`.
- The browser console shows one `401` for `/api/v1/session` before sign-in. That is the expected session probe.
- `apps/web/AGENTS.md` is generated by `next dev` itself. Leave it in place.
