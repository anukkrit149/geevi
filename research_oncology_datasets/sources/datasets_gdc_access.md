# GDC access, data policy and API

Retrieved 11 October 2026. Primary NCI documentation; high authority for repository policy, not a guarantee of clinical completeness or product fitness.

- https://gdc.cancer.gov/access-data/data-access-processes-and-tools — read in gstack. Open files need no login; controlled files require authorization. Most clinical and all biospecimen elements are open; low-level sequencing, germline data and some clinical fields are controlled.
- https://gdc.cancer.gov/access-data/data-access-policies — read in gstack. Open data still follows NIH Genomic Data Sharing policy: no participant identification and acknowledge dataset/accession/repository. Controlled uses must satisfy dataset limitations. Quote: “Not attempt to identify individual human research participants from whom the data were obtained.”
- https://docs.gdc.cancer.gov/API/Users_Guide/Search_and_Retrieval/ — read in gstack. API supports case/file/project metadata, filters, expansion, JSON/TSV/XML response formats, file sizes and access indicators.
- https://gdc.cancer.gov/content/gdc-and-artificial-intelligence-ai — browser navigation timed out; read-only retrieval fallback read successfully. Describes research AI uses, not blanket approval of any commercial or clinical application.
